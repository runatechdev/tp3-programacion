## 🚀 Inicio Rápido

```bash
# Activar entorno virtual
source .venv/bin/activate

# Crear datos de prueba
python manage.py crear_datos_prueba

# Ejecutar servidor
python manage.py runserver

# Acceder a http://127.0.0.1:8000/login/
# Usuario: admin / Contraseña: admin123
```
